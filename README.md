# Mazrati-android
مزرعتي | Mazraati

1. نبذة عن المشروع

مزرعتي مشروع تقني يهدف إلى بناء منظومة تجمع بين لعبة زراعية افتراضية على أندرويد وسوق حقيقي مستقل، مع إمكانية التوسع مستقبلًا إلى خدمات ومنتجات زراعية رقمية وواقعية.

2. مكونات المشروع

Mazraati Play

لعبة زراعية افتراضية يبدأ فيها اللاعب بمزرعة صغيرة وموارد مجانية، ثم يطوّر مزرعته تدريجيًا من خلال الزراعة والرعاية وإدارة الموارد والإنتاج.

Mazraati Market

سوق حقيقي مستقل عن اللعبة، يتيح مستقبلًا عرض المنتجات الزراعية وبيعها وشراءها وفق القوانين والأنظمة المعمول بها.

3. المبادئ الأساسية

- الفصل التام بين الاقتصاد الافتراضي والأموال الحقيقية.
- نقاط الخبرة (XP) مخصصة للتقدم وفتح المستويات، ولا تتحول إلى أموال.
- توفير بداية مجانية وعادلة لجميع اللاعبين.
- الاعتماد على الرعاية والإنتاج وإدارة الموارد في تقدم اللعبة.
- عدم معاقبة اللاعب بقسوة عند الغياب.
- عدم استخدام الرهانات أو صناديق المكافآت المدفوعة.
- استقلال السوق الحقيقي عن اقتصاد اللعبة.
- حماية بيانات المستخدمين وتطبيق ممارسات أمنية مناسبة.

4. الرؤية التقنية

- تطوير اللعبة لتعمل على أجهزة أندرويد.
- بناء المشروع تدريجيًا مع توثيق الشيفرة والقرارات التقنية.
- تصميم بنية قابلة للتوسع والصيانة.
- اختبار الوظائف قبل اعتمادها.
- فصل بيانات اللعبة عن بيانات السوق الحقيقي عند الحاجة.

5. مراحل التطوير المقترحة

1. تأسيس المستودع وتنظيم ملفات المشروع.
2. إعداد نموذج أولي قابل للتشغيل للعبة.
3. تطوير نظام المزرعة والمحاصيل والإنتاج.
4. إضافة نظام الخبرة والمستويات والعملة الافتراضية.
5. اختبار الأداء وسهولة الاستخدام والأمان.
6. التخطيط المستقل لبناء Mazraati Market.

6. حالة المشروع

المستودع في مرحلة التأسيس. ستُحدّث هذه الوثيقة مع تقدم التنفيذ، وستُوثّق الميزات المنجزة والقرارات التقنية في ملفات المشروع المناسبة.
