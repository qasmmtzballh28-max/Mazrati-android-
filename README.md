# Mazrati-android 

Mazraati | مزرعتي

1. نبذة عن المشروع

مزرعتي مشروع تقني يجمع بين لعبة زراعية افتراضية لأجهزة أندرويد وسوق حقيقي مستقل عنها، مع إمكانية التوسع مستقبلًا إلى خدمات ومنتجات زراعية رقمية وواقعية.

2. مكونات المشروع

Mazraati Play

لعبة زراعية افتراضية يبدأ فيها اللاعب بمزرعة صغيرة وموارد مجانية، ثم يطور مزرعته تدريجيًا من خلال الزراعة والرعاية والإنتاج وإدارة الموارد.

Mazraati Market

سوق حقيقي مستقل عن اللعبة، يهدف إلى إتاحة عرض المنتجات الزراعية وبيعها وشرائها وفق القوانين والأنظمة المعمول بها.

3. المبادئ الأساسية

- العملة الافتراضية منفصلة تمامًا عن الأموال الحقيقية.
- نقاط الخبرة (XP) تفتح المستويات ولا تتحول إلى أموال.
- تبدأ اللعبة بموارد مجانية وفرص عادلة للتقدم.
- يعتمد الإنتاج على الرعاية وإدارة الموارد.
- لا توجد عقوبات قاسية على اللاعب بسبب الغياب.
- لا توجد رهانات أو صناديق مكافآت مدفوعة.
- السوق الحقيقي مستقل عن اقتصاد اللعبة.
- حماية بيانات المستخدمين أولوية أساسية.

4. الرؤية التقنية

- تطوير لعبة تعمل على أجهزة أندرويد.
- تنظيم ملفات المشروع وتوثيق الشيفرة والقرارات التقنية.
- بناء نظام قابل للتوسع والصيانة.
- اختبار الوظائف قبل اعتمادها.
- فصل بيانات اللعبة عن بيانات السوق الحقيقي عند الحاجة.

5. مراحل التطوير

1. تأسيس المستودع وتنظيم الملفات.
2. إعداد نموذج أولي قابل للتشغيل.
3. تطوير المزرعة والمحاصيل والإنتاج.
4. إضافة الخبرة والمستويات والعملة الافتراضية.
5. اختبار الأداء وسهولة الاستخدام والأمان.
6. التخطيط لتطوير Mazraati Market بصورة مستقلة.

6. حالة المشروع

المشروع في مرحلة التأسيس. ستُحدّث هذه الوثيقة مع تقدم التنفيذ، وستُوثّق الميزات المنجزة والقرارات التقنية في ملفات المشروع المناسبة.
